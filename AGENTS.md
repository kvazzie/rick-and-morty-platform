## Agent skills

### Issue tracker

Issues live as GitHub Issues (uses the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, each label string equal to its name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context (one `CONTEXT.md` + `docs/adr/` at the repo root). See `docs/agents/domain.md`.

### Testing

When creating or changing tests, test infrastructure, or test dependencies, read `TESTING.md` first. It defines test
boundaries, runner, layout, style, and commands.
